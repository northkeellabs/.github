# Northkeel Labs

We build AI agents, MCP servers and automations that run inside a client's own systems, with a person approving before anything is sent or written. Website: [northkeellabs.com](https://northkeellabs.com)

## What we build

- [Official MCP servers for software products](https://northkeellabs.com/mcp): tools that match real tasks, OAuth 2.1 sign-in, read-only access, tests. Guide: [How to give your SaaS product an official MCP server](https://northkeellabs.com/mcp-server-for-your-api)
- [AI agents for leads, email and documents](https://northkeellabs.com/agents): they draft, a person approves
- [Document automation for bookkeeping firms](https://northkeellabs.com/bookkeeping). Guide: [AI invoice extraction without trusting the model](https://northkeellabs.com/invoice-extraction-for-bookkeepers)
- Workflow fixes. Guide: [Why n8n runs the same webhook twice, and how to fix it](https://northkeellabs.com/n8n-duplicate-webhook-runs)
